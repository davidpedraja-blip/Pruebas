# 🎮 Juego de Coger Colores

Un divertido juego interactivo donde debes atrapar objetos de colores que caen desde el cielo usando una cesta controlada por el mouse.

## 🎯 Cómo Jugar

- Mueve el mouse para controlar la cesta
- Atrapa los círculos de colores que caen
- ¡Gana 10 puntos por cada objeto atrapado!
- Tienes 3 vidas - pierdes una vida si un objeto llega al suelo
- Intenta conseguir la puntuación más alta posible

## 🚀 Desplegar en Netlify

### Opción 1: Despliegue desde GitHub (Recomendado)

1. Ve a [Netlify](https://www.netlify.com/) y crea una cuenta o inicia sesión
2. Haz clic en "Add new site" → "Import an existing project"
3. Selecciona "Deploy with GitHub"
4. Autoriza a Netlify para acceder a tu cuenta de GitHub
5. Busca y selecciona el repositorio `davidpedraja-blip/Pruebas`
6. Selecciona la rama: `claude/cabbage-catching-game-011CUmpnEDqayLY89JPt78BS`
7. La configuración de build debería detectarse automáticamente (gracias al archivo `netlify.toml`)
8. Haz clic en "Deploy site"
9. ¡Tu juego estará disponible en unos segundos!

### Opción 2: Despliegue Manual (Drag & Drop)

1. Ve a [Netlify](https://www.netlify.com/)
2. Arrastra la carpeta del proyecto directamente al área de "drag and drop"
3. ¡Listo!

## 🎨 Características

- Sistema de puntuación en tiempo real
- Sistema de vidas (3 vidas)
- Objetos de colores aleatorios
- Diferentes velocidades de caída
- Animaciones suaves
- Interfaz responsive
- Pantalla de Game Over con opción de reiniciar
